_o problema

Quase sempre, o problema começou antes do primeiro clique no software.

  • Arquivo salvo em três lugares, sem saber qual é a versão certa.
  • Ninguém sabe quem aprova o quê, e o projeto volta várias vezes.
  • Cada pessoa modela de um jeito, e o modelo não conversa.
  • Detalhe demais onde não precisava e de menos onde fazia falta.

Esses erros nascem quando o projeto começa sem combinados claros. O Kit de Projeto BIM mostra como fazer esses combinados e onde registrá-los, para que o modelo avance sem retrabalho.

A lógica do Kit

Entender, falar a mesma língua e aplicar.

O Kit foi pensado para quem ainda está começando em BIM. Por isso ele não entrega só um documento para preencher: primeiro explica como um projeto BIM funciona.
